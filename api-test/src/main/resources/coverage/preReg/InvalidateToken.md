**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Logs the caller out — invalidates their current login session so the `Authorization` cookie `ValidateOtp.md` issued can no longer be used to authenticate further requests.

**Request & response**

Empty request body:
```
POST /preregistration/v1/login/invalidateToken
{}
```
On success, `response` = `"Loggedout successfully"`, and the server also clears the `Authorization` cookie on the HTTP response (sets it with `maxAge=-1`).

**Who can call it**

Any authenticated caller may invalidate their own token — there's no `@PreAuthorize` role restriction on this endpoint at all, since logging out isn't a privileged operation. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
