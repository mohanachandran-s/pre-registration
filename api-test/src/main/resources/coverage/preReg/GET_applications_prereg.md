**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Returns all pre-registration applications created by the logged-in user, with their basic demographic details and status, for the "Your Applications" page.

**Request & response**

No body; an optional `pageIndex` query parameter pages the result. The response is a `DemographicMetadataDTO` with the list of applications.

**Who can call it**

`REGISTRATION_OFFICER, INDIVIDUAL, REGISTRATION_SUPERVISOR, REGISTRATION_ADMIN`; anyone else gets HTTP 403. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
