**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Cancels a booked appointment. It is the internal twin of the public cancel endpoint and is used by the pre-registration batch job (for example when bookings expire or a centre closes).

**Request & response**

No body — just the `preRegistrationId` in the path. The response carries a `CancelBookingResponseDTO` with the cancellation message and time.

**Who can call it**

`REGISTRATION_OFFICER, INDIVIDUAL, PRE_REGISTRATION_ADMIN`; anyone else gets HTTP 403. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
