**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Returns the latest published UI specification — the definition the pre-registration UI uses to render its forms.

**Request & response**

Optional query parameters `version` and `identitySchemaVersion` (both default to 0, meaning latest). The response is a `UISpecMetaDataDTO`.

**Who can call it**

`REGISTRATION_OFFICER, REGISTRATION_SUPERVISOR, REGISTRATION_ADMIN, INDIVIDUAL`; anyone else gets HTTP 403. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
