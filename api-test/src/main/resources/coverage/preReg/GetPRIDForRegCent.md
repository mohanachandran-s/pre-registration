**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Used to list the pre-registration IDs with bookings at a given registration centre within a date range — conceptually similar to `GetBookingsForRegCenter.md`, but keyed toward the PRID list rather than full booking detail rows.

**Request & response**

No request body — `registrationCenterId` is a path parameter, `from_date`/`to_date` are query parameters. This subject's YAML uses:
```
GET /preregistration/v1/appointment/preRegistrationId/{registrationCenterId}?from_date=2020-10-01&to_date=2034-10-13
```
On success, the response echoes `registration_center_id` among presumably a list of matching PRIDs (no other fields are asserted by any current case). On failure, `errors[0].errorCode` = `PRG_BOOK_RCI_032` for an invalid registration centre.

**Who can call it**

Set by the booking service, whose code is not in this repo — confirm the role list there (see Technical details). _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
