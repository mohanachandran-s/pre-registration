**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Lists the metadata for every document uploaded against a pre-registration application — one call to see everything the applicant has submitted so far (which categories are filled, which are still missing), rather than fetching each document individually.

**Request & response**

No request body — `preRegistrationId` is a path parameter:
```
GET /preregistration/v1/documents/preregistration/{preRegistrationId}
```
On success:
```json
{
  "response": {
    "documentsMetaData": [
      { "docId": "98745627893456", "docName": "doc_POA.pdf", "docCatCode": "POA", "docTypCode": "RNC" },
      { "docId": "12345678901234", "docName": "doc_POI.pdf", "docCatCode": "POI", "docTypCode": "CIN" }
    ]
  },
  "errors": null
}
```
On failure (application not found), `errors[0].errorCode` = `PRG_PAM_APP_005`.

**Who can call it**

The applicant themselves, or registration-centre staff (an officer, supervisor, or admin), may list an application's documents. Anyone else is rejected with HTTP 403. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
