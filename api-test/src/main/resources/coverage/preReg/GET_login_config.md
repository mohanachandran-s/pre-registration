**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Gives the pre-registration UI the global and pre-registration configuration it needs before the user logs in.

**Request & response**

No request body or parameters. The response is a map of configuration keys to values.

**Who can call it**

Anyone, before login — there is no role rule on this endpoint (see Notes on the `authn` row). _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_

<details>
<summary>Technical details (automation + verification notes)</summary>

`LoginController.configParams` (class mapping `/login`) has no `@PreAuthorize`. Anonymous access depends on kernel-auth-adapter's public-URL configuration, which is outside this repo.
