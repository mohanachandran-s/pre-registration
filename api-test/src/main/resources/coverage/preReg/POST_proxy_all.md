**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Forwards any `POST /proxy/masterdata/...` call from the pre-registration UI to the masterdata service, such as the applicant-type lookup.

**Request & response**

The body and path after `/proxy` are forwarded as-is; the response is masterdata's own.

**Who can call it**

Anyone the UI serves — there is no role rule on this endpoint. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
