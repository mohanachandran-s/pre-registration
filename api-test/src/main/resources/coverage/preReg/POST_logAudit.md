**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Records an audit event raised by the pre-registration UI (page views, button clicks and similar) into MOSIP's audit trail, so user actions in the browser are traceable server-side.

**Request & response**

The standard envelope with a `UIAuditRequest` in `request` (event id/name/type, description, module details). The response is a plain success message.

**Who can call it**

The applicant or registration-centre staff (`REGISTRATION_OFFICER, INDIVIDUAL, REGISTRATION_SUPERVISOR, REGISTRATION_ADMIN`); anyone else gets HTTP 403. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
