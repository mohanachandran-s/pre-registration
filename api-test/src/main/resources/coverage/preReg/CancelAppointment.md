**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

*Intended* to cancel a booked appointment for a pre-registration application, freeing the reserved slot and reverting the application's status. See the ⚠️ Technical details below for a concern about whether this subject reaches the real endpoint.

**Request & response**

No request body — `preRegistrationId` is a path parameter. This subject's YAML uses:
```
PUT /preregistration/v1/appointment/{preRegistrationId}
```
On success, no distinct fields are asserted by any current case (`checkErrorsOnlyInResponse: true`). On failure, `errors[0].errorCode` = `PRG_APP_013` (application not found) or `PRG_BOOK_RCI_013` (nothing valid to cancel — already canceled, never booked, or in an incompatible state).

**Who can call it**

Intended to be the applicant themselves, a registration-centre officer, or a pre-registration admin, based on the equivalent role rule documented for `CancelApplicationsAppointment.md`'s confirmed-correct endpoint. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
