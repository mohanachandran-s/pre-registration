**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Permanently discards a pre-registration application — for example, when an applicant decides not to proceed, or a test/demo record needs cleanup. This is a hard delete of the demographic record identified by `preRegistrationId`; nothing in the response suggests a soft-delete/undo path.

**Request & response**

No request body — `preRegistrationId` is a path parameter only:
```
DELETE /preregistration/v1/applications/prereg/{preRegistrationId}
```
On success, the response confirms who deleted it and when (`MainResponseDTO<DeletePreRegistartionDTO>`):
```json
{
  "id": "mosip.pre-registration.demographic.delete",
  "version": "1.0",
  "responsetime": "2026-08-07T10:00:01.000Z",
  "response": {
    "preRegistrationId": "98745627893456",
    "deletedBy": "the caller's user ID",
    "deletedDateTime": "2026-08-07T10:00:01.000Z"
  },
  "errors": null
}
```

**Who can call it**

Only the applicant themselves, or registration-centre staff (an officer, supervisor, or admin) acting on the applicant's behalf, may delete a pre-registration. Anyone else is rejected with HTTP 403. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
