**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Forwards any `GET /proxy/masterdata/...` call from the pre-registration UI to the masterdata service and returns its response unchanged, so the browser never talks to masterdata directly (story MOSIP-10807).

**Request & response**

Whatever the target masterdata endpoint takes: the path after `/proxy` is forwarded as-is, with the query string. The response is masterdata's own response.

**Who can call it**

Anyone the UI serves — there is no role rule on this endpoint (see Notes on the `authn` row). _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
