**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Same as `GET /sync/{preRegistrationId}`, but prepares the archive for a specific registration-client machine.

**Request & response**

No body — `preRegistrationId` and `machineId` in the path. The response is a `PreRegArchiveDTO`.

**Who can call it**

Registration-centre staff (`REGISTRATION_OFFICER, REGISTRATION_SUPERVISOR, REGISTRATION_ADMIN`); anyone else gets HTTP 403. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
