**About this endpoint**

**What this endpoint does**

Same purpose as `FetchApplicationByPrid.md` — fetches the full demographic identity record for a pre-registration application. This subject's YAML happens to test that endpoint for the positive case, but (per the 🛑 finding below) its negative case actually lands on the different `/applications/prereg/info/{id}` endpoint that `GetPreRegInfoByPrid.md` documents.

**Request & response**

For the intended `/applications/prereg/{preRegistrationId}` unit, see `FetchApplicationByPrid.md`'s Request & response — identical endpoint, identical flat `DemographicResponseDTO` response shape.
