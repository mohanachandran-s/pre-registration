**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Generates a QR code for a piece of text — used by the acknowledgement page so the applicant can show their pre-registration id as a scannable code.

**Request & response**

The standard envelope with the text to encode as `request`. The response is a `QRCodeResponseDTO` containing the QR image.

**Who can call it**

`REGISTRATION_OFFICER, INDIVIDUAL`; anyone else gets HTTP 403. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
