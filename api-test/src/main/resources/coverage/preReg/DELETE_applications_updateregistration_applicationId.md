**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Deletes (withdraws) an update-registration application the applicant created with `POST /applications/updateregistration`.

**Request & response**

No body — the `applicationId` in the path. The response is a `DeleteApplicationDTO` echoing the id and who deleted it when.

**Who can call it**

`INDIVIDUAL, REGISTRATION_OFFICER, REGISTRATION_SUPERVISOR, REGISTRATION_ADMIN`; anyone else gets HTTP 403. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
