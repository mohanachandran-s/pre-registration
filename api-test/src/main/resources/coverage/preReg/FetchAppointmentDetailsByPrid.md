**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Fetches the appointment details (registration centre, date, time slot) booked for a pre-registration application — the confirmed-correct endpoint for this purpose. See `GetAppointmentDetails.md` for a sibling subject that, per a static-code finding, may be hitting a nonexistent path for the same intended purpose.

**Request & response**

No request body — `preRegistrationId` is a path parameter:
```
GET /preregistration/v1/applications/appointment/{preRegistrationId}
```
On success:
```json
{
  "response": {
    "registration_center_id": "10003",
    "appointment_date": "2026-08-20",
    "time_slot_from": "09:00:00",
    "time_slot_to": "09:15:00"
  },
  "errors": null
}
```
On failure, `errors[0].errorCode` = `PRG_APP_013` (application not found) or `PRG_BOOK_RCI_013` (no active booking to report, e.g. for an expired application).

**Who can call it**

The applicant themselves, or a registration-centre officer, may fetch appointment details. Anyone else is rejected with HTTP 403. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
