**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Used to fetch the appointment details (registration centre, date, time slot) booked for a pre-registration application — the read counterpart to `bookAppointment.md`. This path is served by the separately deployed booking service, not by the code in this repo (see Technical details).

**Request & response**

No request body — `preRegistrationId` is a path parameter. This subject's YAML uses:
```
GET /preregistration/v1/appointment/{preRegistrationId}
```
On success, the response includes `registration_center_id` among other booking fields (see `FetchAppointmentDetailsByPrid.md` for a fuller documented response shape, since that subject's endpoint is the one confirmed to exist).

**Who can call it**

Intended to be the applicant themselves, or a registration-centre officer, based on the equivalent `getAppointmentdetailspreregid` role rule documented on `FetchAppointmentDetailsByPrid.md`. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
