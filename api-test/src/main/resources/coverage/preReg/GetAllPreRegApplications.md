See that file for the full request/response contract and role documentation; this subject exists as a separate set of scenarios (baseline, "with lost-UIN applications present", "with a deleted application present") over the identical `GET /applications` call.

**Request & response**

See `GetAllApplications.md` — identical call shape (`GET /preregistration/v1/applications`, no request body) and identical response envelope (`response.allApplications[]`).
