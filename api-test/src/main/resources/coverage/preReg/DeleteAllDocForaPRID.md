**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Deletes every document uploaded against a pre-registration application in one call — the bulk counterpart to `DeleteSpecificDocForaPRID.md`'s single-document delete, used when an applicant needs to start their document set over from scratch.

**Request & response**

No request body — `preRegistrationId` is a path parameter:
```
DELETE /preregistration/v1/documents/preregistration/{preRegistrationId}
```
On success, `response.message` confirms the deletion. On failure (application not found), `errors[0].errorCode` = `PRG_PAM_APP_005`.

**Who can call it**

Only the applicant themselves (`INDIVIDUAL`) may delete all their documents at once. Anyone else is rejected with HTTP 403. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
