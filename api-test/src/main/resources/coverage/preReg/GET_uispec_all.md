**About this endpoint**

**What this endpoint does**

Lists every published UI specification, page by page.

**Request & response**

Query parameters `pageNumber` (default 0) and `pageSize` (default 10). The response is a page of `UISpecMetaDataDTO`.

**Who can call it**

`REGISTRATION_OFFICER, REGISTRATION_SUPERVISOR, REGISTRATION_ADMIN, INDIVIDUAL`; anyone else gets HTTP 403. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
