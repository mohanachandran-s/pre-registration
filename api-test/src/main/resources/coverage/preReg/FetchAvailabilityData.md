**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Lists the open appointment slots (dates and time windows) available at a given registration centre. This is the confirmed-correct endpoint for slot availability — `bookAppointment.md`'s automation calls exactly this endpoint live before every booking to discover a real slot — and `GetAvailableSlotForRegCentreId.md` documents a sibling subject that, per a static-code finding, may be hitting a nonexistent path for the same intended purpose.

**Request & response**

No request body — `registrationCenterId` is a path parameter:
```
GET /preregistration/v1/applications/appointment/slots/availability/{registrationCenterId}
```
On success:
```json
{
  "response": {
    "regCenterId": "10003",
    "slots": [
      { "date": "2026-08-20", "fromTime": "09:00:00", "toTime": "09:15:00" }
    ]
  },
  "errors": null
}
```
On failure, `errors[0].errorCode` = `KER-MSD-215` for an unrecognized registration centre.

**Who can call it**

The applicant themselves, or a registration-centre officer, may check slot availability. Anyone else is rejected with HTTP 403. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
