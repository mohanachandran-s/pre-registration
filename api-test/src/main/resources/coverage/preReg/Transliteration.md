**About this endpoint**

**What this endpoint does**

Converts a piece of text from one script/language to another (e.g. a Latin-script name transliterated into Arabic script) — a standalone utility used wherever this module needs to display or store the same value in multiple languages, independent of any specific application record.

**Request & response**

```
POST /preregistration/v1/transliteration/transliterate
{
  "id": "mosip.pre-registration.transliteration.transliterate",
  "version": "1.0",
  "requesttime": "2026-08-11T10:00:00.000Z",
  "from_field_value": "string",
  "from_field_lang": "eng",
  "to_field_lang": "ara"
}
```
On success:
```json
{
  "from_field_value": "string",
  "from_field_lang": "eng",
  "to_field_value": "سترِنگ",
  "to_field_lang": "ara"
}
```
On failure, `errors[0].errorCode` = `PRG_TRL_APP_002` if either language code isn't one the environment supports.

**Who can call it**

Registration-centre officers, supervisors, admins, or the applicant themselves may call this. Anyone else is rejected with HTTP 403. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
