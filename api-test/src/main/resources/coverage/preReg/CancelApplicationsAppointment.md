**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Cancels a booked appointment for a pre-registration application, freeing the reserved slot and reverting the application's status. This is the confirmed-correct endpoint for appointment cancellation — see `CancelAppointment.md` for a sibling subject that (per a static-code finding) may be hitting a nonexistent path for the same intended purpose.

**Request & response**

No request body — `preRegistrationId` is a path parameter:
```
PUT /preregistration/v1/applications/appointment/{preRegistrationId}
```
On success, no distinct fields are asserted by any current case (`checkErrorsOnlyInResponse: true`). On failure, `errors[0].errorCode` = `PRG_APP_013` (application not found) or `PRG_BOOK_RCI_013` (nothing valid to cancel).

**Who can call it**

The applicant themselves, a registration-centre officer, or a pre-registration admin may cancel an appointment. Anyone else is rejected with HTTP 403. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_

No YAML in this module targets that internal path, which is expected — it's not part of the public API surface this coverage matrix tracks.

**`PRG_BOOK_RCI_013`** — same not-defined-anywhere-in-this-repo caveat as `bookAppointment.md`'s `PRG_BOOK_RCI_*` codes; not repeated in full here.
