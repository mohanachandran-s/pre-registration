**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Used by the registration client to fetch the ids of all applications booked at its centre in a date range — every booking type, unlike the older `POST /sync`, which `GetPRIDByDateRange` covers.

**Request & response**

The standard envelope with a `DataSyncRequestDTO`: `registration_center_id`, `from_date`, `to_date`. The response is an `ApplicationsDTO` listing the ids.

**Who can call it**

Registration-centre staff (`REGISTRATION_OFFICER, REGISTRATION_SUPERVISOR, REGISTRATION_ADMIN`); applicants and anyone else get HTTP 403. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
