**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Gives the registration client everything about one pre-registration (demographics and documents) as a single archive, so the operator can start the registration from it.

**Request & response**

No body — the `preRegistrationId` in the path. The response is a `PreRegArchiveDTO` containing the archive.

**Who can call it**

Registration-centre staff (`REGISTRATION_OFFICER, REGISTRATION_SUPERVISOR, REGISTRATION_ADMIN`); anyone else gets HTTP 403. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
