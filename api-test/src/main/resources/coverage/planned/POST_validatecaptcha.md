**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Checks a captcha token from the login page with the captcha provider, so OTPs are only sent to humans (see `planned/POST_login_sendOtpWithCaptcha.md`).

**Request & response**

The standard envelope with a `CaptchaRequestDTO` in `request` holding the token. The response says whether the token is valid.

**Who can call it**

Anyone, before login — there is no role rule on this endpoint. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_
