**About this endpoint**

<!-- ENDPOINT:details -->
**What this endpoint does**

Sends a login OTP to the user's email or phone, but only after verifying a captcha token — the bot-protected version of `/login/sendOtp/langcode`.

**Request & response**

The standard envelope with `OTPRequestWithLangCodeAndCaptchaToken` in `request`: `userId` (email or phone), `langCode` and `captchaToken`. The response confirms the OTP was sent.

**Who can call it**

Anyone, before login — there is no role rule on this endpoint. _(How the login credential itself is transported is the same for every endpoint in this module — see `README.md`'s "How authentication works in this module".)_

<details>
<summary>Technical details (automation + verification notes)</summary>

`LoginController.sendOtpWithCaptcha` (class mapping `/login`) has no `@PreAuthorize`. The captcha token is checked by the separate captcha service (see `planned/POST_validatecaptcha.md`).
